# CartCollision — моделирование неупругого столкновения тележек

![Столкновение тележек](images/monkeycart.jpg)

CartCollision

1. Название эксперимента

Абсолютно неупругое столкновение двух тележек

Проект разработан в рамках дисциплины «Виртуальный физический эксперимент», вариант 11 по источнику Кононова.

2. Описание задачи

Цель проекта — создать компьютерную модель столкновения двух тележек, позволяющую исследовать изменение их движения в результате абсолютно неупругого удара.

Пользователь задаёт массы и начальные скорости тележек, запускает эксперимент и наблюдает движение объектов до столкновения, в момент контакта и после него.

После столкновения тележки движутся с общей скоростью. Программа рассчитывает эту скорость на основе закона сохранения импульса и позволяет сохранить результаты моделирования в CSV-файл для дальнейшего анализа.

3. Физическая модель

Рассматривается одномерное абсолютно неупругое столкновение двух тележек. Предполагается, что внешние силы, влияющие на суммарный импульс системы, отсутствуют или их воздействием можно пренебречь.

До столкновения тележки имеют массы (m_1), (m_2) и скорости (v_1), (v_2). После столкновения они движутся совместно с общей скоростью (v').

Направление движения учитывается знаком скорости: скорости тележек, движущихся навстречу друг другу, имеют противоположные знаки.

4. Используемые формулы

Закон сохранения импульса

Суммарный импульс системы до столкновения равен суммарному импульсу после столкновения:

[
m_1v_1+m_2v_2=(m_1+m_2)v'
]

Отсюда определяется общая скорость после удара:

[
\boxed{v'=\frac{m_1v_1+m_2v_2}{m_1+m_2}}
]

Кинетическая энергия

Кинетическая энергия до столкновения:

[
E_{\text{до}}=\frac{m_1v_1^2}{2}+\frac{m_2v_2^2}{2}
]

Кинетическая энергия после столкновения:

[
E_{\text{после}}=\frac{(m_1+m_2)(v')^2}{2}
]

При абсолютно неупругом столкновении кинетическая энергия не увеличивается. Её часть переходит в другие формы энергии.

7. Инструкция по запуску

Программу можно запустить двумя способами.

Способ 1. Запуск готовой сборки

Этот вариант позволяет использовать программу без открытия Visual Studio.

Перейдите в раздел GitHub Releases.

Скачайте архив с готовой сборкой CartCollision.

Распакуйте архив в отдельную папку.

Запустите CartCollision.exe.

Не удаляйте DLL и другие файлы, находящиеся рядом с исполняемым файлом. В зависимости от конфигурации компьютера может потребоваться установленный .NET Framework 4.7.2 или совместимая более новая версия.

Способ 2. Запуск из Visual Studio

Этот вариант подходит для изучения исходного кода, отладки и дальнейшей разработки.

Склонируйте репозиторий или скачайте исходный код с GitHub.

Откройте решение CartCollision.sln в Microsoft Visual Studio.

Убедитесь, что необходимые проекты и зависимости загружены.

При необходимости восстановите зависимости.

Выберите проект CartCollision в качестве запускаемого.

Нажмите F5 для запуска с отладкой или Ctrl + F5 для запуска без отладки.

8. Информация о Windows Forms

Пользовательский интерфейс приложения реализован с использованием Windows Forms на языке C#.

Windows Forms обеспечивает отображение графических элементов управления, ввод параметров эксперимента, запуск моделирования и визуализацию движения тележек.

Движение объектов обновляется во время выполнения симуляции, а результаты расчётов отображаются в интерфейсе. Для экспорта результатов предусмотрено сохранение данных в CSV-файл, который можно открыть в Microsoft Excel.

Основные технологии проекта:

Язык программирования: C#.

Пользовательский интерфейс: Windows Forms.

Платформа: .NET Framework 4.7.2.

Среда разработки: Microsoft Visual Studio.

Контроль версий: Git и GitHub.

Формат экспорта данных: CSV.

9. Результаты проверки модели

В рамках проверки программы рассматриваются следующие критерии:

корректность ввода параметров и обработка ошибочных значений;

движение тележек до столкновения;

правильная фиксация момента столкновения;

корректность движения после абсолютно неупругого удара;

соответствие общей скорости закону сохранения импульса;

корректность отображения выбранных цветов тележек;

возможность повторного запуска эксперимента;

сохранение результатов моделирования в CSV-файл.

Сквозное тестирование пользовательского сценария выполнено. Готовая сборка создана в конфигурации Release, её запуск проверен, а экспорт данных проверен в Microsoft Excel.

Автоматические тесты вычислительной модели используются для проверки физических расчётов и граничных случаев.
