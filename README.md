# CartCollision — моделирование неупругого столкновения тележек

![Столкновение тележек](images/monkeycart.jpg)

## О проекте

**CartCollision** — учебный проект по дисциплине «Виртуальный физический эксперимент». Программа предназначена для моделирования движения двух тележек и визуализации их абсолютно неупругого столкновения.

Пользователь задаёт массы, начальные скорости и цвета тележек. Программа должна отображать движение тележек до столкновения, момент контакта и совместное движение после столкновения.

## Постановка задачи

Две тележки массами \(m_1\) и \(m_2\) движутся навстречу друг другу с начальными скоростями \(v_1\) и \(v_2\).

Необходимо разработать программу, которая:
- рассчитывает движение тележек до столкновения;
- определяет момент столкновения;
- рассчитывает общую скорость после столкновения;
- визуализирует движение до, в момент и после столкновения;
- позволяет выбирать цвет каждой тележки;
- проверяет корректность введённых параметров.

## Физическая модель

Рассматривается **абсолютно неупругое столкновение**: после столкновения тележки движутся совместно с одинаковой скоростью.

Скорости задаются со знаком в зависимости от выбранного положительного направления оси.

По закону сохранения импульса:

m_1v_1+m_2v_2=(m_1+m_2)v'

Отсюда общая скорость после столкновения:

v'=(m_1v_1+m_2v_2)/(m_1+m_2)

где:
m_1, m_2 — массы тележек, кг;
v_1, v_2 — начальные скорости тележек, м/с;
v' — общая скорость после столкновения, м/с.

При расчётах необходимо учитывать направления движения тележек. Если тележки движутся навстречу друг другу, их скорости имеют противоположные знаки.

## Технологии

- **Язык программирования:** C#
- **Платформа:** Windows Forms
- **Среда разработки:** Visual Studio
- **Система контроля версий:** Git
- **Совместная разработка:** GitHub

## Архитектура проекта

Проект разделяется на три основные части:

- **Core** — физическая модель, расчёты движения и проверка физических законов.
- **UI** — пользовательский интерфейс, ввод параметров, выбор цветов и визуализация движения.
- **Integration** — соединение физической модели с интерфейсом, сквозное тестирование и подготовка проекта.

Физические расчёты не должны зависеть от элементов Windows Forms, а пользовательский интерфейс не должен самостоятельно реализовывать физическую модель.

## Командная работа

Работа распределена между тремя участниками:

| Роль | Ответственность |
|---|---|
| TeamLead | Организация разработки, интеграция, тестирование и документация |
| Core | Физическая модель и проверка корректности расчётов |
| UI | Пользовательский интерфейс и визуализация |

Для управления задачами используются GitHub Issues. Изменения разрабатываются в отдельных ветках и передаются в основную ветку `main` через Pull Request.

## Статус проекта

На текущем этапе подготовлены репозиторий, проект Windows Forms, структура задач и процесс совместной разработки.

Реализация физической модели, пользовательского интерфейса и их интеграция выполняются поэтапно.

## Проверка корректности

В ходе разработки необходимо проверить:
- соблюдение закона сохранения импульса;
- правильность определения момента столкновения;
- корректность общей скорости после столкновения;
- обработку недопустимых входных параметров;
- правильность визуализации движения до и после столкновения.

## Запуск проекта

1. Клонировать репозиторий.
2. Открыть файл `CartCollision.sln` в Visual Studio.
3. Собрать решение.
4. Запустить приложение клавишей `F5`.

Инструкция будет актуализирована по мере реализации функциональности.
